⚙ 전자문서 AI 요약 — 설정

⚠ 문서 본문이 어디로 가는지 확인하세요. 기본값은 내부 LLM입니다.
  • Gemini로 바꾸면 요약 대상 문서의 본문 전체가 Google 서버(국외)로 전송됩니다. 개인정보가 담긴 공문서·민원 문서에는 사용하지 마세요. 업무 문서를 외부 AI 서비스에 보내는 것은 소속 기관의 정보보안·개인정보 처리 지침 위반일 수 있으니 먼저 확인하세요. 무료 등급 API는 제출한 내용이 서비스 개선에 이용될 수 있습니다.
  • 내부 LLM(Ollama 등)을 고르면 문서가 지정한 서버 밖으로 나가지 않습니다. 기관 문서에는 이쪽을 권장합니다.
Gemini 키 발급: aistudio.google.com/apikey · 내부 LLM은 필요 시에만 입력
키는 프로바이더별로 따로 저장되며(전환해도 서로 전송되지 않음), 이 기기에만 보관됩니다.
내부 LLM은 서버에서 설치된 모델 목록을 자동으로 불러옵니다
비워두면 로컬 Ollama(http://localhost:11434, API 키 불필요). 내부 서버는 주소 입력 (뒤에 /v1/chat/completions 자동 부착). 원격 주소는 https 권장 — 평문 http면 문서 본문과 키가 그대로 네트워크에 흐릅니다.
쉼표로 구분. 정확한 호스트와 그 하위 도메인에만 적용됩니다(부분 문자열 매칭 아님). 저장할 때 해당 주소에 대한 접근 권한을 요청하며, 승인해야 버튼이 표시됩니다. 변경 후 해당 페이지를 새로고침해야 적용 — 우클릭 메뉴·툴바 팝업은 주소와 무관하게 어디서나 동작합니다.
전자문서 첨부는 다운로드가 막혀 있어(보안문서 정책) 뷰어의 간편 미리보기로만 내용을 읽을 수 있습니다. 이 옵션을 켜면 확장이 첨부에 우클릭 → 미리보기를 대신 수행해 내용을 분석합니다. 동작 중 "…에서 디버깅하고 있습니다" 알림 막대가 잠시 표시됩니다(브라우저 디버거 API 사용). 끄면 첨부는 파일명만 요약에 반영됩니다. 저장을 눌러야 적용됩니다.
